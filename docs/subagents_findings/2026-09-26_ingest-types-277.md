# SQL-source ingest: declared types, safe names, per-Space tables, serving sync (dms#277 F-b..F-e)

Keywords: VARCHAR, INFORMATION_SCHEMA.COLUMNS, type_bronze_columns, untyped_numeric, timestamptz, ident_safe, manifest_key_invalid, claim_source_table_name, space_scoped, serving_sync, dms-277
Main idea: Land SQL-source columns as their declared types, only when every value converts exactly; name every column that stays text, and refuse SQL that reads a declared-numeric text column. Keep bronze names ASCII. Claim names per Space before writing. Sync to the serving warehouse and put the result on the receipt.

PREFLIGHT: PARTIAL (INGEST-OPS and SPACE-GEN-01 findings named VARCHAR as a BIRD cost; nothing fixed it).

## Expected vs actual (before)

- F-e: `SUM(s.budget)` over a numeric(10,2) source column failed validation, because bronze was VARCHAR.
- F-c: one `bronze.2024_sales` made `cortex_row_predicates` raise `manifest_key_invalid`, so every ask in the Space abstained `submit_failed`.
- F-d: Space B's pull of the same source rewrote Space A's table and re-tagged it as B's.
- F-b: the serving warehouse never received SQL-source bronze.

## Repro

`tests/test_ingest_fixes_277.py`. The mutations `mut_types`, `mut_space`, `mut_ident`, `mut_sync`, `mut_grant` and `mut_num` each turn their tests red.

## Root-cause class

A lossy boundary: types were dropped at extract (`str()` of every value), names were sanitised without checking the rule the next layer enforces, and ownership was keyed on the source instead of source plus Space. Fixing the boundary, not each symptom.

## Adversary round 4

Typing shifted zoned timestamps (a new P0, now kept as text), and text MAX on untyped numerics (P0, now refused by name). Also found:
- DuckDB rounds `'1.5'` into BIGINT instead of failing (now an exactness check);
- a refused claim left half a pull landed (now claim-first);
- case-duplicate columns caused a 500 (now `_2`).

My own claim-first change then broke the in-batch collision case (`dbo.a-b` and `dbo.a_b`); the existing test caught it and reserved in-batch names fix it.

## Invariants

Silent fallback is a lie: every untyped column is named. Prove a gate can fail: the mutations above. Adversary is not the verifier.

## Ceiling

- Zoned timestamps stay text, so date maths on them uses the source's clock text.
- The `untyped_numeric` refusal matches on column name only (it can refuse a same-named column of another table).
- A table landed under a legacy digit name is ungranted until it is re-ingested.

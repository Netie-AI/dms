# GRANT-READ-02 refuse by name before any Cortex or model call (dms#307)

Keywords: GRANT-READ-02, grant_unreadable, GroundingRefused, grounding_not_grantable, R-0005, live_ask, Insights, silent drop, dms-307, dms-297
Main idea: `Executor.live_ask` reads the Space grant once, at the top, before the follow-up, verified, pack, cascade, Insights and Cortex ask lanes. An unread grant is a named ABSTAIN `grant_unreadable` with zero Insights posts, zero Cortex asks and zero submits. An empty grant is the same ABSTAIN on the generative and exact lanes; on the product lane it skips only the Insights call, so a document-only Space still reaches the manifest-bound Cortex ask. A ticked table outside the grant raises the existing `GroundingRefused` (R-0005), which the route already renders as 403 `grounding_not_grantable` naming the table and the next step. Only narrows. Not COMPLETE.

## Expected vs actual (parent `87a9497`)

- (a) Expected: unread grant gives a named refusal and no model call. Actual: the generative lane sent an Insights generate call with an empty schema; on the product lane the second grant read raised and the route returned 500 `live_ask_failed`.
- (b) Expected: a ticked ungranted table is refused by name. Actual on the generative lane: `requested` dropped it, `readable` fell back to the demo tables, and `POST /v1/chat/ask` returned 200 generic ABSTAIN with `grounded_tables: []`. The product lane already refused late, in `demo_acl`, after the cascade and generative lanes.

Repro: `tests/test_grant_read_02.py` with the two prod files stashed: 10 of 10 new tests fail, plus the one edited #297 assertion.

## Root-cause class

The grant check lived in one lane (`demo_acl`, last on the ladder) while earlier lanes read the grant themselves with their own fallback. A boundary enforced per lane is skipped by whichever lane answers first.

## Invariant

"Silent fallback is a lie": the empty context and the dropped tick were both silent. "Fix the root-cause class": one grant read, before every lane.

## Ceiling

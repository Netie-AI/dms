Main idea: `score_pack_live` judges the rows that were served. A `DMSMASK_` token in a column the oracle compares is INVALID `masked_compare:<col>`, kept in n, never CORRECT or WRONG. `overmask_star:dms#284` counts INVALID answers whose SQL uses `*` or UNION and a masked typed date.

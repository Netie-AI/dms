Main idea: `DMS_VQ_RAG` is default off, so exact-match replay stays. When the flag is on, `lookup_verified_query` and `maybe_verified_ask` return nothing. Similar Space rows are few-shot examples for the SQL writer, never the answer. Similarity uses the Cortex client's `embed` or `embeddings` method when it exists (no model name, no provider key). Otherwise Okapi BM25 over word-character tokens. A reconfirm Yes, or a vote whose readings agree and whose checker passed, stores one question, SQL, schema hash, and provenance (`yes:reconfirm` or `yes:vote`) per Space. Revoked rows are not retrieved. A listed pack, SQL, or result hash is not written. Prove pin `279cbd85` was not edited.

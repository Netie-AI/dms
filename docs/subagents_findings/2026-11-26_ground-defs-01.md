# GROUND-DEFS-01

Keywords: GROUND-DEFS-01, DMS_GROUND_DEFS, definition_mismatch, audit_overdue, rank_texts, BM25, sqlglot, WORD-RULES-OUT-01, governed definitions

Main idea: Flag default 0. On, the ask's own ontology is ranked with the verified-example embedder, or BM25 when the embedder is absent. Top 3 above 0.5 are written into the Insights question as `governed definitions; use exactly` (name, grain, expression, as_of). Verified examples from the DMS_VQ_RAG path sit in that same block and are not also sent as `vq_examples`. The L2 check compares the normalized predicate on the measure's columns. A mismatch reconfirms `definition_mismatch` and does not park the SQL, so Yes re-asks. The token locks in `semantic_retrieve` stay until WORD-RULES-OUT-01. `DMS_SCHEMA_CONTEXT` was not added to `ARMED_ALL_FLAGS_ON`.

Measured locally, no embedder: "Which suppliers have an audit overdue?" BM25 score 6.647 on `audit_overdue` and 0 on the other demo measures, so the 0.5 floor keeps only that rule. The 1 YEAR invention does not match `CURRENT_DATE - INTERVAL 90 DAY`. A synthetic measure whose name, description, and expression share no tokens with the question is grounded only when the embedder scores it.

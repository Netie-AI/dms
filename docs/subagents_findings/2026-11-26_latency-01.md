# LATENCY-01

Keywords: LATENCY-01, DMS_ASK_LEAN, timings, ask clock, cancel, rank_texts, grade52, insights_timeout, crew-think

Main idea: Every ask envelope carries a `timings` block (monotonic stage spans, prompt chars, estimated tokens, model calls, abandoned calls). It is not a served field and is not in the vendored OpenAPI pin. `DMS_ASK_LEAN` default off. On, four cuts: cancel the HTTP client and POST `/v1/insights/cancel` when a leg or the ask deadline gives up; skip the second reading when the first SQL already checked; cap schema, ontology, and governed definitions at `DMS_ASK_LEAN_TRIM_TOKENS` (default 1200) using `rank_texts`; one model POST at a time unless `DMS_CLOOP_B` voting is on. Flag off does not trim, cancel, skip, or take the lock. The compliance gate stays on the path. Cortex does not yet expose the cancel route.

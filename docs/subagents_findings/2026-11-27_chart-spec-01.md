# CHART-SPEC-01

PREFLIGHT: PARTIAL. INDEX mentions chart_from_rows and SimpleChart. Nothing covers a model chart spec.

Keywords: CHART-SPEC-01, DMS_CHART_SPEC, summarize, chart_spec, chart_adjust, pie, stacked, multi_line, scatter, chartShape

Main idea: `DMS_CHART_SPEC` defaults off. Off, `attach_chart_spec` returns the same envelope and builds no prompt, so `chart` and `route` stay as they are. On, one OpenVault call uses role `summarize` and a body of column names, types, and row count. Cell values are not in that body. The reply `{kind, x, y, series}` is kept only when every name is a result column and the shape can be drawn. Otherwise `chart_spec` is absent and Studio keeps `chartFromRows`. `chart_adjust` is the kind and axis list `validate_spec` accepts. Pie, stacked, multi-line, and scatter are SVG in `SimpleChart` and plot finite result cells. A non-positive cell is omitted on pie and stacked, not drawn as a positive. Not PASS.

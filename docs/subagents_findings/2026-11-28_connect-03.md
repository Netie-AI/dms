# DMS-CONNECT-03

Flags `DMS_CONNECT_S3`, `DMS_CONNECT_AZURE`, and `DMS_CONNECT_SALESFORCE` default off. Only the digit 1 turns one on. Oracle stays on `DMS_CONNECT_ORACLE`.

S3 and Azure Blob download a granted CSV or Parquet only when it is under the byte cap, then aggregate in local DuckDB. A larger file is `byte_limit`, not a prefix sum. Azure SQL and the Oracle ask path use a row cap and a statement timeout. Salesforce is SOQL over the recorded fixture. The schema map is names and types. Credentials are the OpenVault JSON the connect book already resolves. No Alembic revision. Not PASS.

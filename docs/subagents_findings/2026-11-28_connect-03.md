# DMS-CONNECT-03

Flags `DMS_CONNECT_S3`, `DMS_CONNECT_AZURE`, and `DMS_CONNECT_SALESFORCE` default off. Only the digit 1 turns one on. Oracle stays on `DMS_CONNECT_ORACLE`.

S3 and Azure Blob download a granted CSV or Parquet only when it is under the byte cap, then aggregate in local DuckDB. A larger file is `byte_limit`, not a prefix sum. Azure SQL and the Oracle ask path use a row cap and a statement timeout. The Oracle page alias starts with a letter. `_dms_page` is ORA-00904. A table created seconds earlier returns ORA-01466 (SCN lag). The ask retries that code three times, one second apart. Salesforce is SOQL over the recorded fixture. The schema map is names and types. Credentials are the OpenVault JSON the connect book already resolves. Docker Hub no longer serves `minio/minio`, so CI uses `pgsty/silo`, the same server and the same S3 API. No Alembic revision. Not PASS.

## What

`DMS_CREATE_APP` defaults off. Only the digit 1 turns the generate, preview, publish, query, action, and chain routes on. `GET /v1/studio/apps/status` stays mounted and reports `enabled: false` while the flag is off. `DMS_CREATE_APP_SALESFORCE` is a separate digit-1 flag.

The provider returns one `dms.app/1` JSON bundle: `index.html`, `server.py`, declared queries, and declared actions. DMS writes `dms_data.py`. The backend reaches data only through that client, which posts to the app query route. The model receives table names, column types, and granted ontology links. Samples, cell values, and ungranted tables are dropped. SQL still passes `serve_gap` and `run_readonly`.

Actions: `writeback` calls `propose_action` then `apply_action_version` when `DMS_ACTIONS=1` and a connection is bound. `salesforce` create or update uses a secret from the injected secrets port. Env `SALESFORCE_*` is ignored. Dry-run never calls HTTP. Confirm needs an `approval_ref` of at least 3 characters and is the user route. The sandbox data server returns 403 on `/actions/confirm`. Connector `ontology` returns `palantir_ontology_unwired` and makes no HTTP call. This repo has no Palantir ontology-action API to bind.

Chained Create: kinds `doc`, `slides`, and `research`. Context is `context_ref`. A grant outside the app's set is `grant_widened`. Doc and slides call `create_surface.start_session` only when `DMS_CREATE=1`, and pass the stored context into that hook. Research builds a Cursor v1 body. The stored answer or app record is not copied into the prompt.

When `DMS_CREATE_CONTEXT` is the digit 1, generate calls `pack_sources` and `layout_blocks` from `create_context`. There is no second packer. A chat the caller cannot see is `context_forbidden` (HTTP 403). An ungranted table in that chat is left out. The flag off leaves the pack empty.

Run: subprocess of the backend with a stripped env and a socket allowlist of `127.0.0.1` plus the OpenVault host when `OPENVAULT_URL` is set. The judge requires `DMS_APP_READY`, a child query, each declared query ok, and a dry-run that is not applied. Up to two repairs go back to the provider. Spend is `est_cost_usd` or `usage.cost`. No `max_usd`. OpenVault 402 is `budget_exceeded`.

Store reuses `DMS_CREATE_STORE/apps`. The token is returned once. Disk stores the sha256. `#681` and `#682` are still draft and were not edited. Studio mounts `CreateAppPanel` beside `CreateSurface`. The panel renders nothing while the flag is off.

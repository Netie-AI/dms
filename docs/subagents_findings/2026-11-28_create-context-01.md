# Create context

On, Studio Create can save and pick prior chats, a short questionnaire, or a saved project. The server allows the owner and actors on `shared_with`. The pack sent to Claude (OpenVault) or Cursor is summaries, confirmed SQL, a schema and ontology map, and at most 8 rows. An ungranted table is dropped, and so are its SQL and rows. `layout_blocks(kind)` returns nothing. DMS-STYLE-V2-01 fills that hook.

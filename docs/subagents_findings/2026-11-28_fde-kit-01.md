# FDE-KIT-01

Keywords: FDE-KIT-01, DMS_FDE_KIT, netie.fde.report/1, kit.py, engagement, report schema

Main idea: The field-kit launcher is a thin CLI over the existing pipeline. `DMS_FDE_KIT` defaults off and accepts only the digit 1. `list` works with the flag off. Other verbs exit 2 and write nothing. Report status is SKIPPED when there are no checks. A raised kit is a FAIL check with the exception class, and the message is not stored. `run --stage all` calls `fde_pipeline` extract, profile, ontology, and pack. Markdown is rendered from the report JSON. Not PASS.

# FDE-TENANT-01

Keywords: FDE-TENANT-01, tenant_not_provisioned, DMS_TENANT_PROVISION, spaces_tenant_id_fkey, provision_tenant

A missing `dms.tenants` row was an HTTP 500 on `POST /v1/spaces` (`spaces_tenant_id_fkey`). Every route that lets that foreign key out now answers HTTP 409 `tenant_not_provisioned`. The body is the code only. The driver text is not copied.

`DMS_TENANT_PROVISION` defaults off. Off, `scripts/ops/provision_tenant.py` refuses and does not open a connection. On, an operator inserts the tenant row and a default compute pool. The pool write uses `dms_steward`. The command creates no user, membership, key, grant, or credential, and a second run is a no-op. A write route does not create the tenant when the flag is on. The command is operator-run, never automatic.

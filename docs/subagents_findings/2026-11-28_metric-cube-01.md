# FEAT-METRIC-CUBE-01

Keywords: FEAT-METRIC-CUBE-01, DMS_METRIC_CUBE, ai_cube_plan, fan-out, TO_MANY, cube_member_unknown, sqlglot

## Main idea

Approved cubes are steward rows, not word tables. `DMS_METRIC_CUBE` defaults off. On, the model may return a cube plan and the compiler writes dialect SQL. Each TO_MANY child is aggregated on the join key first. An unknown member is `cube_member_unknown` and the ladder continues. A parent measure grouped by a TO_MANY dimension is `fanout_grain` (reconfirm). A shape misfit is `shape_misfit` (reconfirm). The stamp `ai_cube_plan` counts as AI because the model chose the plan. No model id is sent. Role string is `reason`.

## Proof

Order-grain revenue by region is East 140, West 50. The naive join of order_items is East 240, West 150. A sum of line qty does not prove the guard, because that sum is associative.

## Lesson

Do not prove the fan-out guard with a SUM of the child column. SUM is associative, so the bad join and the pre-agg return the same rows. Compare an order-grain measure.

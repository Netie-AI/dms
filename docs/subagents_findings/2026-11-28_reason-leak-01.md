## What

`DMS_REPLY_HYGIENE` defaults off. Only the digit 1 turns it on. Off, `finish_reconfirm` returns the same object.

On, an empty reconfirm (no suggestion, no definition, no SQL) asks OpenVault twice: the free route, then role `escalate`. DMS sends the role string and does not name a provider or a model. If that is still not a checked answer, one role `reason` call may return 1 to 3 readings. If the model returns none, the card uses 1 to 3 granted schema names. There is no Yes token and no plain abstain.

A generate 429 or 5xx, and a serving capacity stop, use the same two rungs. The sentence "I could not reach the model just now; ask again in a minute" is only the exhausted rung, with `reason_code` and a pipeline-failure log.

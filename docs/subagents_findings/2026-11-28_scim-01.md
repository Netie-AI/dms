# SCIM-01

Flag `DMS_SCIM` defaults off. Only the exact digit `1` turns it on. `true`, `yes`, `on`, and a padded ` 1 ` stay off.

Off, `/scim/v2` and `/v1/scim/admin` are not mounted. The space list is unchanged.

On, a SCIM client (Microsoft Entra, or Okta and Google as generic clients) creates, updates, and deactivates users and groups. PATCH operation names are case-insensitive. Pagination is startIndex and count. The enterprise extension carries department and manager. DELETE sets `active` false and leaves the row, so a later GET still returns the user and a filter on userName still finds them.

The provisioning bearer is issued by a manager. OpenVault stores the secret (`POST /api/keys`). DMS stores the sha256 and the cred_ref. The token is returned once and is not logged. Rotation replaces the hash. The protocol path is rate limited. Writes call `compliance_gate` and fail closed when Cortex is down. Reads still answer.

A manager map is an exact, case-insensitive match of a department or a group display name to an SSO role, a governance role, a budget, and space ids. There is no per-company table. The lowest priority number wins. No match leaves the person a viewer with no space filter. A mapped new hire gets the role on the provisioning call. Deactivation revokes SSO sessions in that same call.

The Directory sync panel is inside the governance console, so the panel also needs `DMS_GOV_CONSOLE=1`. The admin API itself needs only `DMS_SCIM=1`.

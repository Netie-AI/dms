# Skills library and Google AI Overview

PREFLIGHT: MISS. No prior finding for a skills library or a Google AI Overview citation.

`DMS_SKILLS` and `DMS_WEB_INSIGHT` default off. Only the digit 1 turns each one on. Off, the skills routes are not mounted, the overview tool is absent from the registry, and Ask and Create return the same objects.

On, a public https skill is pinned to the commit SHA that was checked out. A pin mismatch is rejected. Secrets and dangerous script calls are rejected without echoing the match. A licence is recorded, including `unspecified` when none is present. A grant is per version and per surface. The provider runs the skill. DMS does not.

Documents are chunked excerpts. An embedder that does not return vectors leaves the status `unavailable`. No stand-in vector is stored.

`google_ai_overview` sends `{"query": question}` to `DMS_WEB_INSIGHT_FETCH_URL`. The fetcher is pluggable. CI replays `tests/fixtures/web_insight`. A missing overview, a missing endpoint, a failed fetch, or a rate limit is an empty citation with an honest fallback. `served` and `measured` stay false. Rows are not accepted on the route and are not part of the search payload.

No Alembic migration. The store is a JSON file under `DMS_SKILLS_DIR` because open revisions already collide. Not PASS. A live browser endpoint was not called.

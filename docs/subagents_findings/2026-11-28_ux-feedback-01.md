# UX-FEEDBACK-01

Flag `DMS_FEEDBACK_LOOP`, default off. Off, the feedback router is not mounted and a failed ask does not write a side record. On, Yes on a governed answer, or steward approval of a queued fix, stores the question and the SQL with provenance `feedback_yes` or `feedback_approved`. Lookup does not replay those provenances. Retrieval with the flag on and `DMS_VQ_RAG` off returns only those rows, as writer examples.

Thumbs-down, a failed ask, and Report a problem call the shared pipeline-failure writer and add a row the runs feed can show: question, stage, reason. Fix-it runs `validate_compiled_sql` then `run_readonly` and does not file an example. The interpretation text is not parsed into SQL.
